eAUD Engineering Case Study Website

Files:
- index.html
- styles.css
- script.js
- assets/ (selected screenshots extracted from the project PDFs)

Run locally:
1. Open this folder in VS Code.
2. Use Live Server, or from the folder run:
   python -m http.server 8080
3. Visit http://localhost:8080

The site is plain HTML/CSS/JS so it can be added to an existing portfolio or deployed to GitHub Pages, Netlify, Vercel, or Render.
